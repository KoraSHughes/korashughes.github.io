## Brief Description

Navigating a university campus efficiently can be a challenge for new and returning students alike, especially when locating essential services and resources such as lecture halls, dining areas, and library materials. To address this issue, we present AugmentedLibrary, an augmented reality (AR) application designed to enhance student wayfinding by overlaying interactive, real-time navigation cues onto their physical surroundings. Using AR technology, AugmentedLibrary enables users to visualize paths to key campus locations while also providing an innovative method for book retrieval in the library by directing users to precise shelf locations. The application integrates QR-code localization for outdoor and indoor navigation alongside a computer vision-based positioning methodology for precise guidance. A user-friendly interface ensures accessibility for a broad range of students, reducing the cognitive load associated with traditional map-based navigation. This paper discusses the system architecture, implementation challenges, and user experience findings, providing insights into the potential of AR-enhanced navigation for educational environments.

My primary contribution to this project was the design of the search algorithms that helped disabled students access elevators and transgender students access gender-neutral bathrooms. This was primarily done in C++ and Swift with Xcode's ARKit.
